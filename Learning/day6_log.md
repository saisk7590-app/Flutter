# 📅 Day 6 — Login Screen UI

## 🎯 Goal

Learn how to build a real app-style login screen using user input fields and navigation between screens.

---

## 📚 Concepts Learned

* TextField widget
* InputDecoration
* hintText and labelText
* Password field using obscureText
* Input styling with OutlineInputBorder
* Basic form layout design
* Navigation using Navigator.push
* GestureDetector for clickable text (hyperlink style UI)

---

* Created a Login Screen UI

* Added password input field

* Navigated from Login → Signup screen
* Improved UI spacing and alignment

## 🧠 Key Understanding

* TextField is used for taking user input
* InputDecoration helps style input fields
* obscureText hides password input
* Navigator.push is used for screen navigation
* GestureDetector allows clickable text like hyperlinks
* Proper spacing improves UI readability
